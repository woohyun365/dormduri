# Target & Focus

판정은 WCAG 2.2 AA입니다.

- 터치 타깃은 최소 `target-min`(2.5.8)이고 주 행동은 KNU 목표 `target-primary`(2.5.5 AAA 값)입니다. 예: `min-h-target-min`,
  `min-h-target-primary`.
- focus 표시는 `focus-visible:focus-ring`으로 겁니다. `stroke-focus` 색의 outline이고 offset이 있어 층 배경 위에 그려집니다(층과
  3:1). focus를 가리는 overflow·sticky 배치를 두지 않습니다.
- 면 색이 `stroke-focus`와 겹칠 수 있는 띠는 안의 ring 색을 바꿉니다: 알아두세요 띠 `focus-on-inverse`, 그림 위 `focus-on-media`.
