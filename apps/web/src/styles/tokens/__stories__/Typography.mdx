# Typography

`text-<단계>` 하나가 크기와 줄 간격을 함께 겁니다. 크기는 rem이라 사용자 글자 크기 설정과 200% 확대를 따릅니다. `leading-*`이나
`/tight` 같은 이름 줄 간격으로 바꾸지 않고, 새 단계보다 가까운 단계를 먼저 씁니다.

- **작은 글** `label`, `body-sm`: 보조 설명, label, 목록·표의 작은 본문
- **본문** `body`: 본문
- **제목** `title-3`, `title-2`, `title-1`: section·card·page 제목
- **큰 제목** `display-3`, `display-2`, `display-1`: 랜딩 같은 큰 제목

## 글꼴과 weight

- 글꼴은 `font-body`(Noto Sans KR 계열) 하나이고 새 화면 root에 겁니다. 큰 제목도 `font-body`이고 굵기는 `display-*` 단계가 정합니다.
- weight는 `font-normal`·`font-medium`·`font-bold`만 씁니다.
- 한국어 줄바꿈: 문장은 `break-keep wrap-anywhere`, 제목은 `text-balance`, 긴 본문은 `text-pretty`.
