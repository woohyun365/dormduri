# 3인실 그룹 매칭 라이프사이클 정책

## 문서 범위

이 문서는 3인실(2+1 모델) 그룹 매칭의 호환도 계산, 상태 전이, 신청/대화/확정, 북마크, 리스트 표현, 자발적 이탈, 차단을 다룬다. 2인실 정책은 [matching-lifecycle.md](./matching-lifecycle.md), 채팅방 구조는 [chat-lifecycle.md](./chat-lifecycle.md)를 참조한다.

이 문서가 **3인실 그룹 매칭 상태와 리스트 표현의 최종 소유 문서**다.

### 대상 건물

| 건물   | 인실  |
| ------ | ----- |
| 퇴계관 | 3인실 |
| 난지원 | 3인실 |
| 국지원 | 3인실 |

### 모델

`2+1` 모델을 사용한다.

1. 개인 A와 B가 먼저 2인 확정 (Phase 1: 2인실과 동일)
2. A-B 그룹이 생성됨 (PAIR_OPEN)
3. 개인 X가 그룹에 대화 합류 신청 (`GROUP_CONV_JOIN`)
4. A와 B가 **모두** 수락하면 3인 그룹 대화 진입 (GROUP_FORMING)
5. 3명 모두 확정하면 최종 그룹 확정 (GROUP_FINAL)

### Phase 2+ = ACTIVE 동등 원칙

A-B가 2인 확정(ACTIVE)에 도달한 시점부터 PAIR_OPEN, GROUP_FORMING, GROUP_FINAL은 모두 **ACTIVE 동등**으로 취급한다. 자발적 이탈 불가, 그룹 내 멤버 차단 불가 등 ACTIVE 제한이 동일하게 적용된다.

### 그룹 상태

| 상태          | 의미                        |
| ------------- | --------------------------- |
| PAIR_OPEN     | A-B 페어, 추가 멤버 모집 중 |
| PAIR_FINAL    | A-B 2인으로 마감            |
| GROUP_FORMING | X와 3인 대화 중 (병렬 가능) |
| GROUP_FINAL   | 3인 확정 (전원 동등 Member) |

### 용어

| 용어              | 의미                                                   |
| ----------------- | ------------------------------------------------------ |
| `GROUP_CONV_JOIN` | 그룹 대화 합류 요청. 승인 시 대화 진입 (확정이 아님)   |
| `MEMBER_LEAVE`    | GROUP_FINAL에서 구성원 이탈 요청                       |
| 코어 (A, B)       | PAIR_OPEN~GROUP_FORMING에서 원래 페어 멤버 (역할 기준) |
| Member            | GROUP_FINAL에서 전원 동등한 구성원 (역할 구분 없음)    |

## 호환도 계산

2인실 호환도 계산(비교 구조, 가중치, 표현 원칙)은 [matching-lifecycle.md](./matching-lifecycle.md)와 동일하다.

### 그룹 매칭도

| 항목           | 정책                                                                                                    |
| -------------- | ------------------------------------------------------------------------------------------------------- |
| 그룹 카드 점수 | X 시점에서 `(score(X,A) + score(X,B)) / 2` (평균)                                                       |
| 프로필 시트    | A, B 각각의 개인별 매칭도 표시                                                                          |
| 코어 시점      | A는 `score(A,X)`, B는 `score(B,X)` 각각 표시                                                            |
| 게이팅         | 2인실 score capability와 동일. 필요한 pair 중 하나라도 `scoreVisible = false`면 그룹 카드 점수도 비노출 |

| 항목         | 정책                                                    |
| ------------ | ------------------------------------------------------- |
| 그룹 북마크  | **불가**                                                |

## 상태 전이

### 3인실 상태 전이도

```
Phase 1: A-B 개인 매칭 (2인실과 동일)
--------------------------------------

A->B 신청       B 수락            양측 확정
PENDING ----> IN_CONVERSATION ----> ACTIVE
(5일 TTL)     (7일 TTL)
  |               |
  |-> EXPIRED     |-> CONVERSATION_ENDED
  |-> REJECTED    |
  +-> CANCELLED   +-> (한쪽 종료)

      * ACTIVE 전환 시 A/B 미결 요청 전부 자동 취소
      * A-B 2인방 생성 (이후 시즌 종료까지 유지)


Phase 2: 그룹 확장
--------------------------------------

              +------------------------------+
ACTIVE ---->  |         PAIR_OPEN            |
(A-B 확정)   |  (추가 멤버 모집, 리스트 노출) | <-- 멤버 이탈 시 복원
             |  A-B 2인방 유지               |
             +-------+-----------+-----------+
                     |           |
                     v           v
                PAIR_FINAL    X의 GROUP_CONV_JOIN
                (2인 마감)    요청 (PENDING, 5일 TTL)
                -> 하단정렬       |
                            +-----+------+
                            |     |      |
                            v     v      v
                        EXPIRED  A,B   REJECTED
                        (5일)   모두    (A,B 모두
                                수락    거절 시만)
                                 |
                                 v

Phase 3: 그룹 대화 (병렬 가능)
--------------------------------------

A-B-C 3인방 (7일 TTL)       A-B-D 3인방 (7일 TTL)
+--------------+            +--------------+
|GROUP_FORMING |            |GROUP_FORMING |
|(3인 대화)    |            |(3인 대화)    |
+------+-------+            +------+-------+
       |                          (동일 구조)
 +-----+--------+-----------+
 |     |        |           |
 v     v        v           v
X 자발적 3명 모두  7일 TTL   A-B 그룹
이탈     확정      만료      해체
(승인불필요)|   CONV_ENDED  전원 개인
 |        |    (전원)      (UNMATCHED)
 v        v                 * 모든 3인방
A-B ->  GROUP_FINAL            자동 종료
PAIR_OPEN |
          v

Phase 4: 그룹 확정
--------------------------------------

        +------------------------------+
        |         GROUP_FINAL          |
        |  (3인 확정, 전원 동등 Member) |
        |  하단 정렬, 대화 시즌 종료까지 |
        |                              |
        |  * 확정 시 다른 3인방/요청    |
        |    전부 자동 정리             |
        +-------+----------------------+
                |
                v
         멤버 1명 이탈
        (나머지 1명 동의, +3일 자동승인)
                |
                v
         이탈자 -> 개인
         나머지 2명 -> PAIR_OPEN
```

### 터미널 상태별 재교류 규칙

조합 단위는 **X + (A-B 그룹 엔티티)**이다. 그룹이 해체되면 개인 간은 별개 조합으로 취급한다.

| 터미널 상태          | 출발          | 같은 조합 재신청       | 개인 간 (그룹 해체 후) |
| -------------------- | ------------- | ---------------------- | ---------------------- |
| `EXPIRED`            | PENDING       | 불가                   | 가능 (별개 조합)       |
| `REJECTED`           | PENDING       | 불가                   | 가능 (별개 조합)       |
| `CANCELLED`          | PENDING       | 가능 (방향별 3회 내)   | 가능                   |
| `CONVERSATION_ENDED` | GROUP_FORMING | 양방향 불가 (조합 1회) | 가능 (별개 조합)       |
| `UNMATCHED`          | GROUP_FINAL   | 양방향 불가 (조합 1회) | 가능 (별개 조합)       |

### 차단 시 전이

2인실과 동일 원칙. Phase 2+(PAIR_OPEN~GROUP_FINAL)에서는 그룹 내 멤버 차단 불가.

| 차단 시점 상태                  | 처리                                        | 상대에게 보이는 것               |
| ------------------------------- | ------------------------------------------- | -------------------------------- |
| PENDING (GROUP_CONV_JOIN)       | 자동 취소                                   | "만료"로 표시 (차단 사실 비노출) |
| GROUP_FORMING                   | 해당 3인방 즉시 종료 (`CONVERSATION_ENDED`) | "대화가 종료되었습니다"          |
| PAIR_OPEN~GROUP_FINAL (그룹 내) | **차단 불가**                               | --                               |

### 자발적 이탈 시 전이

| 보유 상태                        | 처리                                               |
| -------------------------------- | -------------------------------------------------- |
| Phase 1 (PENDING/IN_CONV)        | 2인실과 동일 (자동 취소/종료)                      |
| Phase 2+ (PAIR_OPEN~GROUP_FINAL) | **이탈 불가** (그룹 해체/멤버 이탈 절차 선행 필요) |

## 신청 플로우

### Phase 1: A-B 개인 매칭

2인실 신청 플로우와 동일. [matching-lifecycle.md](./matching-lifecycle.md) 참조.

### Phase 2+: GROUP_CONV_JOIN

```
탐색 -> 그룹에 합류 신청(+인트로 메시지) -> A,B 모두 수락 -> 3인 대화 -> 3인 확정
```

### 수치 정책

| 항목           | 정책                                                               |
| -------------- | ------------------------------------------------------------------ |
| 동시 발신 신청 | 3건 (2인실과 동일, 발신자 기준)                                    |
| 신청 만료      | 5일                                                                |
| 만료 리마인더  | 만료 24시간 전 1회                                                 |
| 인트로 메시지  | 10~200자, 필수                                                     |
| 수락 조건      | A, B **모두** 수락                                                 |
| 거절 조건      | A, B **모두** 거절해야 `REJECTED`. 한쪽만 거절 시 5일 후 `EXPIRED` |
| 거절 방식      | 버튼만, 사유 없음                                                  |

### 재신청 규칙

> 재신청 규칙은 **시즌 단위**로 적용된다. 시즌 종료 시 초기화.

| 상황                              | 정책               |
| --------------------------------- | ------------------ |
| 거절/만료 후 같은 그룹 재신청     | 불가               |
| 거절/만료 후 그룹 해체, 개인 신청 | 가능 (별개 조합)   |
| 신청 취소 후 재신청               | 가능               |
| 같은 그룹 같은 방향 시도 수       | 3회 (2인실과 동일) |
| Push 알림                         | 최초 1회만         |

### PAIR_OPEN 진입 시 자동 정리

A-B 2인 확정(PAIR_OPEN) 시, A와 B의 미결 개인 신청/대화를 전부 자동 취소한다.

### GROUP_FINAL 확정 시 자동 정리

확정 시 다른 모든 3인방(GROUP_FORMING)과 미결 GROUP_CONV_JOIN 요청을 자동 종료/취소한다.

## 대화 상태

| 항목                     | 정책                                                       |
| ------------------------ | ---------------------------------------------------------- |
| 대화 중 상태의 타인 노출 | 타인에게 상태 비노출                                       |
| 대화 종료                | X: 승인 없이 자발적 이탈 가능. 코어 일방 종료 없음         |
| 탐색 대화 TTL            | 수락 후 7일 고정 (GROUP_FORMING)                           |
| 확정 대화 TTL            | **시즌 종료 시 만료** (A-B 2인방, GROUP_FINAL 3인방)       |
| 만료 후 상태             | 대화 이력 읽기 가능, 추가 대화 불가 (`CONVERSATION_ENDED`) |
| 종료 전 리마인더         | 만료 24시간 전 1회 (서비스 내 배너)                        |
| 대화 종료 후 재교류      | 양방향 불가 (`조합 1회`)                                   |

### 대화 병렬성

| 항목               | 정책                                    |
| ------------------ | --------------------------------------- |
| 동시 GROUP_FORMING | 무제한 (A-B-C, A-B-D, ... 병렬)         |
| 각 3인방 TTL       | 7일                                     |
| 확정 시            | 1건만. 나머지 3인방/요청 전부 자동 정리 |

### GROUP_FORMING 이탈 규칙

| 행위                     | 승인                      | 결과                                        |
| ------------------------ | ------------------------- | ------------------------------------------- |
| X가 자발적으로 대화 이탈 | **불필요**                | X -> 개인 복귀, A-B -> PAIR_OPEN 유지       |
| 7일 TTL 만료             | --                        | 전원 `CONVERSATION_ENDED`, A-B -> PAIR_OPEN |
| A-B 그룹 해체            | 상대 동의 (+3일 자동승인) | 모든 3인방 자동 종료, 전원 개인 복귀        |

> 코어가 일방적으로 3인 대화를 종료하는 기능은 없다. A-B가 X와의 대화를 끝내고 싶으면: (1) PAIR_FINAL로 2인 마감, (2) 다른 3인방에서 확정하여 시스템이 자동 종료, (3) 7일 TTL 만료 대기. A-B 간 사적 논의는 2인방에서 가능.

## 매칭 확정과 취소

| 항목              | 정책                                           |
| ----------------- | ---------------------------------------------- |
| 확정 조건         | 3명 모두 확정 완료                             |
| 확정 후 상태      | GROUP_FINAL (즉시 잠금, 전원 동등 Member)      |
| 확정 시 자동 정리 | 다른 3인방/GROUP_CONV_JOIN 전부 자동 종료/취소 |

### GROUP_FINAL 이탈 규칙

GROUP_FINAL에서 **코어/비코어 구분은 없다**. 전원 동등한 Member이다.

| 행위          | 승인                                        | 결과                                         |
| ------------- | ------------------------------------------- | -------------------------------------------- |
| 멤버 1명 이탈 | 나머지 2명 중 **1명** 동의 (+ 3일 자동승인) | 이탈자 -> 개인 복귀, 나머지 2명 -> PAIR_OPEN |
| 3인 전체 해체 | 1명 이탈 -> 남은 2명 해체를 순차 진행       | 전원 개인 복귀 (`UNMATCHED`)                 |

## 리스트 표현

### 그룹 카드 원칙

A-B가 그룹을 이루면 **개인 카드는 리스트에서 제거**되고, 그룹 카드로 대체된다. 그룹 카드의 구체적인 형태(뱃지, 정렬, 디자인)는 룸메 리스트 탭 실험에서 결정한다.

| 그룹 상태     | 그룹 카드          | 개인 카드 (A, B) | 비고                                    |
| ------------- | ------------------ | ---------------- | --------------------------------------- |
| PAIR_OPEN     | 활성, 일반 위치    | 제거             | 모집 중                                 |
| PAIR_FINAL    | 하단 정렬 + 비활성 | 제거             | 2인 마감 (2인실 매칭 확정과 동일)       |
| GROUP_FORMING | 활성, 일반 위치    | 제거             | 대화 중이어도 노출, 추가 요청 수신 가능 |
| GROUP_FINAL   | 하단 정렬 + 비활성 | 제거             | 3인 확정 (2인실 매칭 확정과 동일)       |

### 매칭도 표시

X 시점에서 A, B 각각의 매칭도 **평균**을 그룹 카드에 표시. 개인별 상세 점수는 프로필 시트에서 확인.

## 자발적 이탈

| 항목                              | 정책                                                       |
| --------------------------------- | ---------------------------------------------------------- |
| Phase 1 (PENDING/IN_CONVERSATION) | 2인실과 동일 (미결 신청 취소 + 대화 종료 + 리스트 제거)    |
| Phase 2+ (PAIR_OPEN~GROUP_FINAL)  | **이탈 불가**. 그룹 해체 또는 멤버 이탈 절차를 선행해야 함 |

## 사용자 차단 (Block)

### 차단 원칙

Phase 2+(PAIR_OPEN~GROUP_FINAL)는 ACTIVE 동등이므로, **그룹 내 멤버 차단 불가**. 위험 상황은 신고를 통해 관리자가 처리한다 ([incident-enforcement.md](./incident-enforcement.md) 참조).

### 차단의 그룹 전이

차단은 **개인 단위**이며, 그룹에 전이된다.

| 항목                             | 정책                                                                           |
| -------------------------------- | ------------------------------------------------------------------------------ |
| 차단된 상대가 포함된 그룹        | 차단한 사용자의 리스트에서 비노출. 요청 불가                                   |
| 차단한 상대가 포함된 그룹        | 차단된 사용자의 리스트에서 비노출. 요청 불가                                   |
| 차단되지 않은 그룹 멤버의 시점   | 차단 관계가 없는 개인은 **정상 노출** (그룹 상태에서 상호작용 불가하므로 무관) |
| GROUP_FORMING 중 차단            | 해당 3인방 즉시 종료. A-B -> PAIR_OPEN                                         |
| PENDING GROUP_CONV_JOIN에서 차단 | 자동 취소. "만료"로 표시                                                       |
| 그룹 해체 후                     | 차단 관계 유지. 차단 해제 전까지 해당 개인 간 비노출                           |

### 차단과 다른 시스템의 독립성

2인실과 동일. [matching-lifecycle.md](./matching-lifecycle.md) 차단 섹션 참조.
