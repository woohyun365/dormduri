# Supporting — 부모 계획에 딸린 문서

- 문서 유형과 분할 기준: [Plan authoring core](../../docs/development/agent-workflows/plan-authoring/core.md#supporting-detail-and-bounded-plans)
- 재개·인계: [Session continuity — Supporting 문서 재개와 인계](../../docs/development/agent-workflows/session-continuity.md#supporting-문서-재개와-인계)
- 위치·이동 규칙: [Session continuity — Lifecycle 디렉터리와 이동](../../docs/development/agent-workflows/session-continuity.md#lifecycle-디렉터리와-이동)
