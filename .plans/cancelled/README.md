# Cancelled — 취소·대체로 종료한 계획

목표를 달성하지 못한 채 취소되거나 새 설계로 대체된 계획의 **역사 기록**을 `YYYY/MM/<domain>/` 아래에 둡니다.
`finished`와 달리 완료·검증 통과를 뜻하지 않습니다. 실패·미입증 기록은 보존하며, 재개는 현재 source와 요청에 맞는 새
active 계획으로 진행합니다. 과거 PASS를 자동으로 이어받지 않습니다.
